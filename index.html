Claude 액션링

버전 0.9.1 · 팀 내부용 · Windows 10/11

마우스 휠 클릭으로 커서 자리에 원형 메뉴를 띄워, 파일 검색·파일 정리·메모·화면 캡처·Claude 물어보기를 빠르게 쓰는 데스크톱 도구입니다.

⬇ 설치 파일 내려받기

설치

  1. 내려받은 ClaudeRing_설치.zip 의 압축을 풀어요.
  2. 설치.bat 을 더블클릭해요. (파이썬 등 추가 설치 없음)
  3. 바탕화면·시작 메뉴에 바로가기가 생기고, 바로 실행돼요.

처음에 "Windows의 PC 보호" 경고가 나오면 직접 만든 프로그램이라 그런 거예요. "추가 정보 → 실행" 을 누르면 됩니다.

사용

  • 단축키 Ctrl+Alt+Shift+F12 로 마우스 자리에 링이 열려요.
  • 로지텍 마우스는 Logi Options+ 에서 휠 클릭에 위 단축키를 지정하세요.
  • 물어보기·열기는 각자 로그인한 Claude 계정으로 열려요. (API 키 필요 없음)

자동 업데이트

설정 → 일반 → 업데이트 → "업데이트 주소" 에 아래 주소를 넣으면, 새 버전이 나올 때 자동으로 확인하고 받아서 설치해요.

이 페이지 주소 + /version.json
